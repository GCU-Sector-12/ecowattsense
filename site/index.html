EcoWattSense watches every computer in an office or a lab, tells you which ones are active, idle or simply left on, and estimates the energy that goes nowhere.

How it works

Three small parts. A client on each computer, one server, one dashboard. Nothing is installed on the network and no personal data leaves the machine, only a device id and its state.

Active

Someone is working. Keyboard or mouse used in the last few minutes, or the CPU is busy.

Idle

Switched on, screen locked or no input for a while. Could sleep.

Unused

On for hours or days with nobody at it. Should be off.

  • Monitoring client

    Runs in the background. Every five minutes it reads idle time, CPU load and screen lock, decides the state and sends one short report. Windows first, then Linux, then macOS.

  • Server

    Receives the reports, stores them in a database and works out the energy from state and a typical wattage for that type of computer.

  • Dashboard

    One page for the person who looks after the room. Every computer, its state now, its history, and the kWh that could be saved.

client → report every 5 min → server + database → dashboard
