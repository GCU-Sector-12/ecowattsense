# Project site

Public one-page site about EcoWattSense, published with GitHub Pages from the `main` branch by `.github/workflows/pages.yml`.

Plain HTML, CSS and a small script, no build step. Edit `index.html`, open it in a browser to check, open a pull request into `dev`. It goes live when `dev` is merged into `main`.

No personal data beyond team names. No links to Teams or other internal places.
